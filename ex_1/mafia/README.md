# Мафия — симуляция игры на C++20

Консольная эмуляция игры «Мафия» на N > 4 игроков (задание 1, `../2026-Task01.pdf`).

- **Ведущий** моделируется программой. Он единственный, кто меняет состояние партии, и служит точкой синхронизации фаз.
- **Игроки** — иерархия классов по ролям. Каждый живёт в собственной `std::thread` либо, по выбору, в корутине C++20.
- **Общие объекты** хранятся в своём умном указателе `SharedPtr<T>`.
- **Внешних библиотек нет** — только стандартная библиотека C++20. Для ИИ-игроков дополнительно нужна системная программа `curl`.

Состав проекта:
- обязательные роли (мафия, мирный житель, комиссар, доктор, маньяк) и ведущий;
- режим, где пользователь — один из N игроков (`--interactive`), и все игроки-боты;
- открытые и закрытые объявления ведущего (`--open-announcements`), краткий и полный журнал (`--full-log`);
- все 35 дополнительных ролей из задания, выбираются YAML-конфигом;
- журналы в файлах через `std::filesystem`, концепты, ranges, корутины;
- ИИ-агент через бесплатный API.

Одно зерно (`--seed`) даёт одну и ту же партию на обоих движках.

## Требования

- g++ 13 или новее (C++20: концепты, ranges, корутины);
- GNU make (основная сборка) и/или CMake 3.20+;
- Linux; под Windows — WSL (проверено на Ubuntu 24.04, g++ 13.3);
- `curl` в PATH — только для ИИ-игроков (`--ai`).

## Быстрый старт

```sh
make                                   # сборка -> build/make/mafia
./build/make/mafia --players 10 --interactive --open-announcements --full-log   # вы — один из игроков
./build/make/mafia --players 10 --seed 2026
make check                             # всё для сдачи: -Werror, тесты, TSan
```

## Сборка и проверка (Makefile)

| Команда | Что делает |
|---|---|
| `make` / `make build` | собрать `build/make/mafia` |
| `make run ARGS="--players 7"` | собрать и запустить с аргументами |
| `make test` | собрать и прогнать все 21 тест с прогрессом `[i/21] имя... ок (N мс)`; у упавшего печатается весь вывод |
| `make test V=1` | то же, плюс подробный вывод каждого теста и команды компилятора |
| `make tsan` | все тесты под ThreadSanitizer (`build/tsan`); любая гонка роняет цель |
| `make mass` | только массовый тест с таблицами побед; `MAFIA_MASS=3` — втрое больше партий |
| `make strict` | сборка всего (программа, тесты, поддельный сервер) с `-Werror` в `build/strict` |
| `make check` | **одна команда для сдачи**: `strict` + `test` + `tsan` |
| `make fake-server` | поддельный сервис модели для ручной проверки ИИ |
| `make clean` | удалить `build/` |

Флаги во всех сборках: `-std=c++20 -O2 -Wall -Wextra -Wpedantic -pthread`.

## Параметры запуска

```sh
./build/make/mafia --players 10 --seed 2026 --engine coro --full-log
./build/make/mafia --players 12 --config config/example.yaml
MAFIA_AI_KEY=... ./build/make/mafia --ai 3
./build/make/mafia --help
```

| Параметр | Значение | По умолчанию |
|---|---|---|
| `--players N` | число игроков, 5..300; больше 100 — протокол только в журнал, в консоли «Да, это будет долго» с точкой на каждый день и короткий итог (300 игроков — около 2 минут и 2 ГБ памяти) | 8 |
| `--k K` | мафии `floor(N/K)`, но не меньше 1; K ≥ 3 | 3 |
| `--seed S` | зерно партии, 0..2^64−1; одно зерно — одна партия | случайное, печатается |
| `--engine E` | `threads` — нить на игрока, `coro` — корутины | `threads` |
| `--full-log` | полный журнал в файлах (с тайными ходами) | краткий |
| `--log-dir PATH` | каталог журналов | `logs` |
| `--config FILE` | YAML-конфиг: `k` и `extra_roles` (`--k` важнее `k` из конфига) | — |
| `--interactive` | вы — один из N игроков: ведущий подсказывает фазу и спрашивает ваш ход | все — боты |
| `--seat S` | ваше место, 1..N (только с `--interactive`) | по зерну |
| `--open-announcements` | открытые объявления: роль выбывшего, кем убит, кого спасли | закрытые |
| `--ai N` | сколько игроков ведёт ИИ-агент (0..N) | 0 |
| `--ai-url URL` | адрес API (только http/https) | `MAFIA_AI_URL` или `https://vireonix.ai/v1` |
| `--ai-model NAME` | модель | `auto` |
| `--ai-format F` | `openai` (`/chat/completions`) или `anthropic` (`/messages`) | `openai` |
| `--ai-limit L` | обращений к модели за круг на всех ИИ-игроков, 0..1000 | 10 |
| `--ai-timeout S` | ожидание ответа модели, 1..120 с | 20 |
| `--help` | справка | — |

Значение пишется через пробел или через `=`: `--players 10`, `--players=10`.

Любая ошибка в параметрах даёт понятное сообщение, справку и код выхода 2. Например: отрицательное N, неизвестный флаг, повтор флага, лишний хвост в числе.

| Переменная окружения | Значение |
|---|---|
| `MAFIA_AI_KEY` | ключ API. **Только отсюда**: флаги `--ai-key`, `--api-key`, `--key` отвергаются |
| `MAFIA_AI_URL` | адрес API, если не задан `--ai-url` |
| `MAFIA_MASS` | объём массового теста (множитель) |

## Как идёт партия

1. **Раздача.**
   - Мафии `floor(N/k)`, но не меньше одного. Обязательно есть комиссар, доктор и маньяк; остальные — мирные жители.
   - Дополнительные роли из конфига: мафиозные замещают обычных мафиози (хотя бы один остаётся обычным), остальные — мирных.
   - Колода перемешивается. Мафия знает своих.
2. **День.**
   - Утром объявляются ночные смерти, затем выбывшие произносят последнее слово.
   - Обсуждение идёт по кругу, первый говорящий каждый день сдвигается.
   - Голосование. В первый день казни нет — так настроено.
   - Ничья:
     - если равны не все кандидаты (3-3-1) — переголосование между лидерами;
     - если равны все (3-3) — опрос «выгнать всех разом?», нужно «да» больше чем от половины живых.
3. **Ночь.**
   - Ведущий собирает **все** ходы одним пакетом: сначала совет мафии (большинство, при равенстве решает Босс), потом способности.
   - Затем разбирает ночь целиком чистой функцией: кража хода → блокировки → оговор → защиты → нападения → сведения → итог.
4. **Объявления.** Закрытые (по умолчанию): о выбывшем — только «мафия / не мафия», кто убил и кого спасли — тайна. Открытые (`--open-announcements`): «Это был: Комиссар (Мирные). Убит мафией.», «Ведущий: ночью на Игрок 4 напали, но его спасли.».
5. **Конец** проверяется после казни и после утра. Партия также кончается ничьей по пределу дней (317).

Условия победы:

| Состав живых (M — мафия, C — мирные, X — одиночки-убийцы) | Итог |
|---|---|
| никого нет | ничья |
| M = 0 и X = 0 | победа мирных |
| M = 0, X = 1, C ≤ 1 | победа маньяка (одиночки) |
| M > C + X | победа мафии |
| M = C + X и X = 0 | победа мафии (паритет) |
| иначе (в т.ч. M = C + X при живом маньяке) | игра продолжается |

Согласованные уточнения правил:
- **Доктор** не лечит одного и того же две ночи подряд; себя — только один раз за игру.
- **Комиссар** каждую ночь либо проверяет, либо стреляет — как в задании.
- **Маньяк** при проверке выглядит «не мафией».

В конце партии печатаются итог, таблица «кто кем был и как выбыл» и машиночитаемая строка:
```
RESULT winner=mafia reason=mafia_parity days=3 players=9 seed=31 survivors=2,3,5
```

## Игра за столом (`--interactive`)

```sh
./build/make/mafia --players 10 --interactive --seat 3 --open-announcements
```

- В начале — только вам: «*** Вы — Игрок 3. Ваша роль: …», а если вы мафия, то и ваши союзники.
- Перед каждым вашим ходом подсказка ведущего: день, фаза, ваша роль, что вы знаете, допустимые номера.

| Когда | Что вводить |
|---|---|
| обсуждение | текст; `обвинить N текст` — «N — мафия»; `защитить N текст` — «N — мирный»; пустая строка — промолчать |
| голосование | номер игрока из списка |
| «выгнать всех?», палач, некромант | номер варианта |
| ночь | номер действия (если их несколько), затем номер цели; `0` — пропустить, если можно |
| последнее слово | текст |

- **Неверный ввод** — ведущий переспросит.
- **Конец ввода** (Ctrl+D) — дальше за вас играет бот вашей роли, партия доигрывается.
- **Место** без `--seat` выбирается по зерну. ИИ-агентом (`--ai`) ваше место не становится.
- **Режим работает** с обоими движками (`--engine threads|coro`).

## Журналы

Каталог `logs/<дата>_<время>_seed<зерно>[_N]/` (создаётся сам, через `std::filesystem`):

| Файл | Содержимое |
|---|---|
| `round_NN.txt` | всё о круге NN: речи, голоса, смерти; в полном журнале ещё и тайные ходы с пометкой `[ТАЙНО]` |
| `summary.txt` | итог партии и статистика по каждому игроку |
| `ai_dialog.txt` | диалог с моделью (только при `--ai`); содержит роль ИИ-игрока, храните как полный журнал |
| `logs/history.txt` | общая история всех запусков, по строке `RESULT` на партию |

В консоль тайное не попадает никогда — ни в кратком, ни в полном режиме.

**Большие партии (больше 100 игроков).** Весь протокол пишется только в журнал. В консоль выводится:
```
Да, это будет долго ................................................   ← точка на каждый игровой день
Победитель: Мирные (мафия и одиночки-убийцы выбыли).
Дней сыграно: 112, в живых: 64 из 300.
RESULT winner=civilians reason=all_threats_out days=112 players=300 seed=5 survivors=...
Протокол и таблица игроков — в журнале: logs/2026-10-04_21-19-03_seed5
```

## ИИ-агент

- **Что делает.** Игроки, отданные агенту (`--ai N`), днём спрашивают языковую модель о речи, голосе и последнем слове.
- **Запрос.** Системная часть: роль, характер, правила, свои тайные сведения. Сообщение: публичное состояние, история, задание, допустимые цели.
- **Ответ** — JSON:
  ```json
  {"action": "vote", "target": 3, "reasoning": "...", "message": "..."}
  ```
- **Откат на эвристику.** Любой сбой возвращает игрока к обычному боту, партия не падает. Сбоем считается:
  - ошибка сети или код ответа не 200;
  - неверный формат ответа;
  - недопустимая цель или действие;
  - исчерпанный лимит обращений за круг.
- **Ключ** берётся из `MAFIA_AI_KEY` и передаётся `curl` через канал (fd 3). В аргументы процессов, окружение `curl`, журналы и вывод он не попадает.
- **Сервис по умолчанию** — Vireonix (`https://vireonix.ai/v1`, OpenAI-совместимый, ключ не нужен).

Проверка без настоящего сервиса:
```sh
make fake-server
./build/make/fake_llm_server --port 8089                       # терминал 1
./build/make/mafia --ai 3 --ai-url http://127.0.0.1:8089/v1    # терминал 2
```

## Устройство

| Каталог | Содержимое |
|---|---|
| `src/core/` | `SharedPtr<T>` (атомарный счётчик ссылок), генератор `Rng` (xoshiro256** + splitmix64, свой поток на игрока) |
| `src/game/` | модель данных (`types`, `state`, `protocol`), ведущий (`host`), голосование, ночь (`night_rules`), победа (`victory`) |
| `src/roles/` | базовый `Player`, роли, концепты способностей, каталог возможностей, фабрика, оценки ботов (`beliefs`), советник |
| `src/engine/` | интерфейс `Engine` и две реализации: `ThreadEngine` (нить + почтовый ящик на игрока) и `CoroEngine` (корутина на игрока); обёртка `ConsoleEngine` — пользователь за столом |
| `src/log/` | журналы партии в файлах |
| `src/cli/` | параметры командной строки, свой разбор подмножества YAML, конфиг |
| `src/ai/` | ИИ-агент: свой JSON, HTTP через `curl`, запрос, проверка ответа, лимит |
| `tools/` | `fake_llm_server` — поддельный сервис модели |
| `tests/` | 21 тест, каждый — отдельная программа; `test_framework.hpp` — макрос `CHECK` |
| `docs/` | [путеводитель по коду](docs/code_guide.md) (каждый файл: части, строки, почему так), [шпаргалка к защите](docs/defense.md), [экспорт диалога с ИИ](docs/dialog.md) |

Кто меняет данные:
- **`GameState`** меняет только ведущий, в одной нити.
- **Игрок** получает неизменяемый снимок `SharedPtr<const PublicSnapshot>` и личную сводку `Briefing`. Ролей других игроков в них нет по построению.
- **`exchange`** движка («разослать запросы и дождаться всех ответов») — барьер фазы. Поэтому мьютекс на состоянии не нужен.

## SharedPtr<T>

```cpp
#include "core/shared_ptr.hpp"
using mafia::SharedPtr;

auto a = mafia::make_shared_ptr<Dog>();          // одно выделение памяти
SharedPtr<Animal> b = a;                         // наследник -> база, счётчик 2
auto d = mafia::dynamic_pointer_cast<Dog>(b);    // общий блок, счётчик 3
SharedPtr<int> arr(new int[4], [](int* p) { delete[] p; });  // свой удалитель
```

Не поддерживается: weak-указатели, массивы `T[]`, `SharedPtr<void>`, `make_shared_ptr<const T>`.
`SharedPtr` от нулевого сырого указателя — пустой: удалитель не вызывается.
